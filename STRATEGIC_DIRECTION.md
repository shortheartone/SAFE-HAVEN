## Quick Reference

### Our Mission
**Empower users and organizations to securely lock and manage digital assets on the Stellar blockchain, with trustless, community-governed infrastructure that prioritizes transparency, security, and long-term sustainability.**

### Core Values (in priority order)
1. **Security** — User funds protected by code, not people
2. **Decentralization** — Protocol belongs to community forever
3. **Transparency** — All decisions auditable and on-chain
4. **User Empowerment** — Simple to use, hard to break
5. **Sustainability** — Long-term viability over short-term hype

### 3-Year Vision Summary

| Year | TVL | Users | Key Milestones |
|------|-----|-------|---|
| **2027** | $5–10M | 500+ | Mainnet launch, admin renounced, governance active |
| **2028** | $50M+ | 5000+ | Institutional adoption, ecosystem integration |
| **2029** | $100M+ | 5000–10k | Self-sustaining, community-governed, proven trustless |

### Success Criteria (By 2029)

- ✓ $100M+ TVL
- ✓ 5000–10k users
- ✓ 100+ institutional entities
- ✓ 100+ community contributors
- ✓ 80% revenue from community treasury
- ✓ Zero founder dependencies
- ✓ Deployed on 3+ networks
- ✓ Formal security proofs published
- ✓ SOC 2 & ISO 27001 compliance

## Governance

SAFE-HAVEN uses **on-chain, time-locked governance**:

1. **Propose** → Anyone submits with code review + audit evidence
2. **Review** → Independent reviewer confirms
3. **Vote** → Community votes (30%+ participation required)
4. **Timelock** → 14-day delay before execution
5. **Veto** → Any steward can block
6. **Execute** → Anyone can execute after timelock

**Result**: No single person can unilaterally upgrade the contract.

See [GOVERNANCE.md](./GOVERNANCE.md) for details.

## Funding & Sustainability

### Revenue Model (Target by 2029)
- **80%** Community Treasury (early-exit penalties)
- **10%** Grants (declining)
- **10%** Ecosystem Partnerships

### Contributor Incentives
- **Bounties**: $100–$5,000 per contribution
- **Stipends**: $2,000–$5,000/month for stewards
- **Grants**: Retroactive recognition for major contributions
- **Salary**: $80k–$150k/year for core team (elected annually)

See [docs/COMMUNITY_STRATEGY.md](./docs/COMMUNITY_STRATEGY.md) for details.
