Key Implementation Details:
================================================================================

Hash Format:
  commit_hash = Keccak256(token || amount || price || nonce)
  
Input Fields (48 bytes total):
  - token:  20 bytes (Stellar address)
  - amount: 16 bytes (i128, big-endian, two's complement for negatives)
  - price:  8 bytes (u64, big-endian)
  - nonce:  4 bytes (u32, big-endian)

Output:
  - 32 bytes → 64-character lowercase hexadecimal string

Algorithm:
  - Keccak256 (not SHA3-256)
  - Provides 128-bit collision resistance, 256-bit preimage resistance
